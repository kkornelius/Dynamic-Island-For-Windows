# Security

The current public beta is the supported development line. Binaries are unsigned; Releases provide SHA-256 checksums and license notices. Use this repository's Release downloads.

Avoid posting credentials/private Notes in issues. Use GitHub private vulnerability reporting when available; otherwise use the maintainer profile's contact options before sharing sensitive details publicly. Ordinary reproducible bugs can use the issue template.

Notes/preferences are local plaintext under the Windows user profile. This is not an encrypted vault. There is no cloud note-sync or account system. [Data handling](docs/PRIVACY.md).
